# Дальневосточный фестиваль креативной анимации «11 кадров» (г. Чита) 🎬

Официальный веб-портал фестиваля с интерактивной программой, онлайн-приёмом конкурсных заявок, мини-студией покадровой анимации, панелью модератора оргкомитета и интеграцией с реляционной базой данных PostgreSQL и почтовым шлюзом Mail.ru.

---

## 🌟 Ключевые возможности

- **Витрина фестиваля**: Интерактивная программа мероприятий с фильтрацией по дням, номинации, панорама авторских работ, карточки жюри и FAQ.
- **Интерактивная лаборатория «Мини-студия 11 кадров»**: Браузерная покадровая анимация с режимом Onion Skin, регулировкой FPS (1–24 кадров/сек), воспроизведением, экспортом в GIF и генерацией персонажей.
- **Маскот фестиваля — Милаш Анимаш**: Интерактивный анимированный гид-помощник с репликами и быстрыми подсказками.
- **Подача конкурсных заявок**: Пошаговый мастер подачи работ с валидацией, прикреплением ссылок на видео/облако и мгновенной отправкой уведомлений на `chita11kadrov@mail.ru`.
- **Панель оргкомитета (Админка)**:
  - Модерация заявок с изменением статусов («Одобрена», «На рассмотрении», «Отклонена»).
  - Экспорт реестра заявок в CSV (Excel) и JSON.
  - SQL-консоль управления базой данных PostgreSQL.
  - Управление номинациями, жюри, программой и FAQ.
  - Журнал аудита действий и логов отправки email.

---

## 🛠 Стек технологий

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Framer Motion
- **Backend API**: Node.js / Express (`server.ts` + `dist/server.cjs`)
- **База данных**: PostgreSQL 16 (`schema.sql`)
- **Почтовый сервис**: SMTP клиент (`src/lib/mailer.ts`)
- **Инфраструктура**: Docker & Docker Compose, Nginx, PM2, Let's Encrypt SSL

## 🚀 Быстрый запуск на сервере (Docker Compose)

```bash
# 1. Клонируйте репозиторий
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> /var/www/11kadrov
cd /var/www/11kadrov

# 2. Создайте файл окружения
cp .env.production.example .env

# 3. Запустите автоматический деплой
chmod +x deploy.sh
./deploy.sh
```

Подробные инструкции по настройке домена, Nginx, SSL и почты смотрите в файле [`README_DEPLOY.md`](./README_DEPLOY.md).
